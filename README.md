# 🧠 FocusNest AI

FocusNest AI is an AI-powered productivity and focus monitoring web application that helps users stay attentive while studying or working. It uses the device camera and MediaPipe Face Mesh to monitor facial landmarks, estimate focus, and provide real-time motivational feedback.

---

## 🌟 Features

- 🎥 Real-time webcam monitoring
- 🤖 AI-powered face detection using MediaPipe Face Mesh
- 👀 Eye tracking
- 🧠 Real-time focus score calculation
- ⏱ Study session timer
- 📊 Live productivity dashboard
- 💬 Random motivational quotes and suggestions
- 📈 Session report with average focus score
- 🎨 Modern glassmorphism user interface

## 🚀 How It Works

1. Open the application in your browser.
2. Click **Start Monitoring**.
3. Allow camera permission.
4. The AI detects your face using MediaPipe Face Mesh.
5. Focus score is calculated based on:
   - Face detection
   - Eye openness
   - Looking direction
   - Blink activity
6. Click **Start Session** to begin a study session.
7. View your live dashboard:
   - Average Focus
   - Study Time
   - Productivity Level
   - Focus Streak
8. End the session to receive a summary report.
